# Code of Conduct

PostifyX is a community project, and we expect everyone
participating in it — contributors, maintainers, and users in
issues or discussions — to act respectfully.

## Our standards

- Be welcoming and patient with newcomers; everyone was new once.
- Critique ideas and code, not people.
- Assume good faith, and ask before assuming bad intent.
- Keep discussions on-topic and in the right place (issue, PR, or
  discussion).
- Respect privacy: never paste someone else's request data, tokens,
  or URLs without permission.

## Unacceptable behaviour

- Harassment, discrimination, or personal attacks of any kind.
- Trolling, insulting, or derailing conversations.
- Publishing private information without consent.
- Deliberately introducing telemetry, tracking, or anything that
  phones home — this is a project boundary, not a style choice.

## Enforcement

Maintainers may remove, edit, or close comments, issues, or PRs
that violate this code. Repeated violations can result in a ban
from the project. Report conduct concerns to the maintainers
privately (see `SECURITY.md` for contact routes).

## Scope

This code applies within the repository, its issue tracker, and any
official community spaces. Using the software itself is governed by
`TERMS` (see the `/terms` page) and the `LICENSE`.

This code of conduct follows the [Contributor Covenant][cc] format.
